# Contributing

Thank you for interest in ISA 2.0 research documentation.

## Before you open a PR

1. Read [`AGENTS.md`](AGENTS.md) — epistemic labels and forbidden language apply to all edits.
2. Do **not** add files under `docs/CORPUS/raw/` or commit `.env`, credentials, or PII.
3. Keep apostles / messiah / second-coming language as **modeling analogs** only (`INSTITUTIONAL_MODEL`).
4. English for repo scaffolding (README, indices); RU artifact text OK in published corpus when already institutional edition.

## Scope

This repo holds formal matrices and corpus artifacts — not product runtime. Engine math belongs in [errorlogy/errorlogy](https://github.com/errorlogy/errorlogy); umbrella contracts in [ai-native-gov](https://github.com/errorlogy/ai-native-gov).
